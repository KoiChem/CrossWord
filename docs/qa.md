# Phase 5 QA checklist

静的な自動テストだけでは、実機の日本語IMEやソフトウェアキーボードの操作感を保証できない。
公開前には以下を確認する。

## 自動確認

Node.js 20以上で、通常テストと1000盤面の負荷検証を実行する。

```sh
npm test
npm run test:stress
```

通常テストではデータ・Generator・出題履歴・Playerを確認する。負荷検証ではEASY、NORMAL、HARDを各1000 seed生成し、例外、配置制約違反、盤面外配置がないことを確認する。

## ブラウザ表示

ローカルサーバーで次の幅を確認する。

- 390px幅: 盤面・生成ボタンに横スクロールがなく、選択中の単語全体が淡いレモンイエローになる。
- 768px幅: 盤面とヒント領域が重ならず、操作ボタンが押せる。
- 1440px幅: 盤面とヒント領域が2カラムで読みやすく表示される。

各幅でブラウザのconsole errorがないことも確認する。

## 実機での操作確認

iPhone Safari、iPad Safari、Android Chromeの少なくとも各1台で、以下を確認する。

1. 新しい盤面はどの語も選択されていない状態で始まる。
2. 1回タップで語全体が淡いレモンイエローになり、ヒントを読める。
3. 同じ語を続けてタップすると入力モードになり、日本語キーボードが開く。
4. ひらがな、カタカナ、長音符、小書きかなを入力でき、確定後は盤面にひらがなで反映される。
5. 入力中にページを下へスクロールしても、ヒントバーや選択マスによって上端へ戻されない。
6. Backspace、交差マスでのタテ・ヨコ切替、入力後の次マス移動が自然に動く。
7. 正解色をON/OFFしたとき、正解済みの緑表示だけが切り替わる。

実機確認で問題が出た場合は、端末・OS・ブラウザ・画面の向き・再現手順を記録してから修正する。
